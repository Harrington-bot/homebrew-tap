# Homebrew Tap

Formulae published by [Jogvan Kjølbro](https://github.com/jogvan-k).

## Install FitAgent

```sh
brew tap Harrington-bot/tap
brew install fit-agent
```

FitAgent is an agent-friendly CLI that syncs a local fitness workspace with [Intervals.icu](https://intervals.icu). Source and releases: [jogvan-k/fit-agent](https://github.com/jogvan-k/fit-agent).
